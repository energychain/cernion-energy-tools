# Agentic Core Directive

Status: bootstrap placeholder created by Shepherd scan on 2026-10-10T01:04:33.560Z.

Every change that affects chat, OpenWebUI, routing, capabilities, tools, evidence, or HITL must answer:

1. Which Case or process state does it serve?
2. Which Capability exposes it?
3. Which evidence is required before claims or action?
4. Which Tool Contract permits execution, and where is human approval required?
5. How is it visible through OpenAPI and OpenWebUI?
6. Which tests or smoke checks prove the route?
