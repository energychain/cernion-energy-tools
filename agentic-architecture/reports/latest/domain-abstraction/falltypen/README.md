# Energiewirtschaftliche Falltypen

Generated: 2026-10-11T01:32:48.510Z

Dieses Verzeichnis beschreibt natürliche fachliche Falltypen für CET.

Ziel ist nicht, energiewirtschaftliche Praxis zu stark zu algorithmisieren. Ziel ist, wiederkehrende, oft unscharf definierte Arbeitsmuster so zu modellieren, dass CET Fälle strukturieren, Unsicherheit halten und nächste sinnvolle Arbeitsschritte vorbereiten kann.

## Grundregel

CET soll fehlende Evidenz nicht mit fehlender Hilfsfähigkeit verwechseln.

Fehlende Evidenz blockiert:

- finale Behauptungen
- externe Wirkung
- produktive Änderungen
- rechtlich/regulatorisch verbindliche Aussagen

Fehlende Evidenz blockiert nicht:

- Fallstrukturierung
- Hypothesenbildung
- Plausibilisierung
- Rückfragen
- interne Notizen
- Next Best Actions
