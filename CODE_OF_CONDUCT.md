# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, inclusive, and harassment-free experience for everyone who participates in this project.

## Expected Behavior

- Be respectful and considerate in speech and actions.
- Assume good intent and focus on constructive collaboration.
- Give and accept helpful feedback graciously.
- Respect differing viewpoints and experiences.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks.
- Trolling, insulting or derogatory comments.
- Publishing others’ private information without permission.
- Any behavior that would be considered inappropriate in a professional setting.

## Reporting

If you experience or witness unacceptable behavior, please report it by opening a private message to the maintainers or via GitHub Discussions if enabled. If you are unsure how to report, open a standard issue and ask for a private contact path.

## Enforcement

Project maintainers may remove, edit, or reject contributions and temporarily or permanently ban any contributor for behavior they deem inappropriate, threatening, offensive, or harmful.

## Scope

This Code of Conduct applies within all community spaces, and also applies when representing the project in public spaces.

## Attribution

This policy is inspired by common open source community standards and adapted for this project.
