# CoPilot Plan Prompt - v0.54.1 Receipt Test Harness

Use `docs/roadmap/issues/25-runtime-receipts-v054-big-picture.md` as mandatory context before planning.

You are in Plan Mode. Do not implement code yet.

## Goal

Plan v0.54.1: add an isolated receipt validation and test harness.

The system should be able to test/evaluate/explain a receipt without invoking the full Personal Agent chat flow.

## Required Plan Output

Provide:

- actions to add to `agent-receipts`
- helper modules to create or modify
- how to inspect Moleculer action registry for tool availability
- how to validate tool steps and parameter requirements
- how to simulate receipt matching and execution planning
- REST endpoints for test/evaluate/explain
- tests to add
- output contract examples

## Scope

Include:

- `validate` action for schema and tool references
- `test` action with supplied input/context
- `evaluate` action that returns match score, required inputs, planned tool calls, evidence requirements
- `explain` output for debugging why a receipt matched or failed
- registry-based verification of referenced Moleculer actions

Exclude:

- actual Personal Agent chat integration
- automatic receipt promotion
- dynamic chat-based receipt generation
- replacing existing hard-coded VNB routing

## Acceptance Criteria

- A valid receipt can be tested with sample input and returns a structured plan.
- A receipt that references a missing service/action is flagged clearly.
- A receipt with missing required input reports what is missing.
- The test harness can be used through REST without calling `/personal-agent/chat`.
- Tests cover valid, invalid, missing-tool, and missing-input cases.
