# CoPilot Plan Prompt - v0.54.5 Learning Loop / Draft Receipts

Use `docs/roadmap/issues/25-runtime-receipts-v054-big-picture.md` as mandatory context before planning.

You are in Plan Mode. Do not implement code yet.

## Goal

Plan v0.54.5: add a governed learning loop for draft receipts.

The system may propose and store draft receipts from chat/admin workflows, but it must not silently promote or mutate active production receipts.

## Required Plan Output

Provide:

- draft creation flow
- review/promote flow
- audit fields
- safety constraints
- API/action additions
- how chat-submitted receipt changes are represented
- test plan
- rollback/archive behavior

## Scope

Include:

- create draft from structured proposal
- validate/test draft
- promote draft after explicit action
- archive/deprecate old receipt versions
- audit metadata: creator, source, createdAt, updatedAt, promotedAt, promotedBy
- guardrails against direct active mutation through chat

Exclude:

- automatic production self-modification
- LLM-only validation without schema/tool checks
- deleting receipt history

## Acceptance Criteria

- Draft receipts can be created and tested.
- Active receipts cannot be overwritten without explicit promote/update path.
- Promotion records audit metadata.
- Invalid drafts cannot be promoted.
- Tests cover draft creation, failed validation, promotion, and archive/deprecation behavior.
