# Cernion v0.52.0 — Zwiebelmodus & Kontext-Management

**Meilenstein:** v0.52.0
**Scope:** Personal Agent Service — Kern der kontextuellen Schichtung (Layer 0–4), Session-Lifecycle und Token-Budget-Management.
**Ziel:** Jede Nutzer-Nachricht baut einen deterministischen, token-optimierten Kontext-Stack auf. Layer 4 ist transient und verlustfrei.

## Aufgabe für Copilot
Implementiere den Zwiebel Context Manager als zustandslosen Baustein. Jeder Chat-Turn führt zu einem exakten Kontext-Stack (L0 → L4).
- **Hartes AK: Layer-4 Datenverlust-Prävention:** L4 darf niemals mehr als ein aktives Tool halten. Roh-JSON muss nach Synthese explizit entfernt werden.
