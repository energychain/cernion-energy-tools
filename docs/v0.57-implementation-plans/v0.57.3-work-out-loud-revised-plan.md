# v0.57.3 Work Out Loud — Final Implementation Plan

**Status:** Planning — Final (no implementation yet)
**Date:** 2026-05-28
**Addressed Corrections:** 9 safety/concurrency constraints (first revision) + 8 final constraints (this revision)
**Target Release:** v0.57.3 (after v0.57.2)

---

## 1. Product Definition

**Goal:** Provide transparent, sanitized visibility into Personal Agent workflow decisions without exposing private context, tenant data, or internal reasoning.

**User Outcome:** Multi-turn chat responses include `agentTrace.workLog[]` — a chronological list of high-level activities (routing classified, onboarding gap detected, knowledge consulted, etc.) with stable, whitelisted metadata fields.

**Safety Principles:**
- Per-turn local accumulator only (no `this.workLog` instance storage)
- Unknown/invalid entries dropped silently in service paths; strict validation in test helpers only
- All metadata: primitives and controlled enum-code arrays only — no nested objects, no free-text arrays
- No `confidence`, `personaId`, `tenantId`, `userId`, `sessionId`, `reasoning`, `payload`, or raw context in any metadata field
- Minimal stable callsites for v0.57.3 — no broad threading through unrelated execution paths
- `toArray()` returns a frozen immutable copy

### Overflow Strategy

When `totalActivities` (see Section 4) exceeds 16 retained entries, the first 8 are kept, then a truncation marker is inserted, then the last 7 are kept. The truncation entry uses `totalActivities` from the separate counter — not the entry array length — so the count remains correct after multiple overflow events.

```javascript
// Example truncation entry (step 9 when 23 activities were observed)
{
  step: 9,
  timestamp: "2026-05-28T14:30:46.900Z",
  action: "worklog_truncated",
  label: "Activity log trimmed: 23 activities in this turn",
  metadata: {
    totalActivities: 23,
    retainedFirst: 8,
    retainedLast: 7,
    droppedMiddle: 8
  }
}
```

### Hard Constraints

- **workLog location:** Only `agentTrace.workLog`. Never in `reply`, never in any other field.
- **Max retained entries:** 16 (8 first + 1 truncation marker + 7 last)
- **All labels:** max 120 characters, user-facing prose only
- **Metadata values:** primitives (`string`, `number`, `boolean`) and controlled enum-code arrays (`enum_array`) only
- **`toArray()`:** returns `Object.freeze([...this.entries])` — immutable snapshot

## 4. Per-Turn Local Accumulator Design

### Pattern: Request-Scoped Closure

The workLog is **never** stored on `this` (service instance). It is a local closure created fresh at the start of each `_executeChatCoreLogic()` invocation.

```javascript
// src/personal-agent-work-log.js
function createTurnWorkLog() {
  let totalActivities = 0; // Separate counter; survives multiple overflow events

  const entries = [];      // Mutable internal array; never exposed directly

  function addEntry({ action, label, metadata = {} }) {
    if (!VALID_WORK_LOG_ACTIONS.has(action)) {
      return null; // Silent drop in service path
    }

    totalActivities += 1; // Always increment, even if entry will be overflowed away

    const sanitized = sanitizeWorkLogEntry({
      action,
      label: String(label || '').slice(0, 120).trim().replace(/[\x00-\x1f]/g, ''),
      metadata: sanitizeWorkLogMetadata(action, metadata),
    });

    if (!sanitized) return null;

    entries.push({
      step: entries.length + 1,
      timestamp: new Date().toISOString(),
      ...sanitized,
    });

    if (entries.length > 16) {
      _applyOverflowStrategy();
    }

    return sanitized;
  }

  function _applyOverflowStrategy() {
    if (entries.length <= 16) return;
    const first8 = entries.slice(0, 8);
    const last7 = entries.slice(-7);
    const truncationEntry = {
      step: 9,
      timestamp: new Date().toISOString(),
      action: WORK_LOG_ACTIONS.WORKLOG_TRUNCATED,
      label: `Activity log trimmed: ${totalActivities} activities in this turn`,
      metadata: {
        totalActivities,          // from closure counter, not entries.length
        retainedFirst: 8,
        retainedLast: 7,
        droppedMiddle: totalActivities - 15,
      },
    };
    entries.length = 0;
    entries.push(
      ...first8,
      truncationEntry,
      ...last7.map((e, i) => ({ ...e, step: 10 + i }))
    );
  }

  function toArray() {
    // Immutable snapshot — callers cannot mutate the internal entries array
    return Object.freeze([...entries]);
  }

  return { addEntry, toArray };
}
```

### Key Invariants

1. `totalActivities` always reflects total `addEntry()` calls regardless of overflow events
2. `entries.length` is always <= 16 after `_applyOverflowStrategy()`
3. `toArray()` returns `Object.freeze([...entries])` — a snapshot callers cannot mutate
4. `VALID_WORK_LOG_ACTIONS.has(action)` gates every entry — unknown actions return `null` silently
5. turnWorkLog is created once per request and goes out of scope when `_executeChatCoreLogic()` returns

### 5.3 sanitizeWorkLogMetadata() and sanitizeMetadataField()

```javascript
function sanitizeWorkLogMetadata(action, inputMetadata = {}) {
  const allowlist = WORK_LOG_METADATA_WHITELIST[action];
  if (!allowlist) return {};
  const output = {};
  for (const [key, fieldSpec] of Object.entries(allowlist)) {
    const value = inputMetadata[key];
    if (value === undefined || value === null) continue;
    try {
      output[key] = sanitizeMetadataField(value, fieldSpec);
    } catch (_err) {
      // Drop field — do not throw in service path
    }
  }
  return output;
}

function sanitizeMetadataField(value, fieldSpec) {
  const { type, maxLength, enumValues, enumCodes } = fieldSpec;
  switch (type) {
    case 'string': {
      const str = String(value || '').slice(0, maxLength || 64).trim();
      if (enumValues && !enumValues.includes(str)) {
        throw new Error(`Invalid enum value: ${str}`);
      }
      return str;
    }
    case 'number': {
      const num = Number(value);
      if (!Number.isFinite(num)) throw new Error('Invalid number');
      return num;
    }
    case 'boolean':
      return Boolean(value);
    case 'enum_array': {
      // Controlled arrays of pre-defined code strings only.
      // No free-text strings from runtime sources pass through.
      if (!Array.isArray(enumCodes) || enumCodes.length === 0) {
        throw new Error('enum_array field requires enumCodes definition');
      }
      if (!Array.isArray(value)) throw new Error('Not an array');
      const validCodes = new Set(enumCodes);
      return value.filter(v => validCodes.has(String(v))).slice(0, 10);
    }
    default:
      throw new Error(`Unknown field type: ${type}`);
    // NOTE: 'array' type is intentionally absent.
    // All arrays must be 'enum_array' with a defined enumCodes list.
  }
}
```

### 5.5 validateWorkLogEntry() — Test-Level Validator

```javascript
// Throws on any violation. Used only in unit test helpers — never in service path.
function validateWorkLogEntry(entry) {
  if (!entry || typeof entry !== 'object') throw new Error('Entry must be an object');
  if (!VALID_WORK_LOG_ACTIONS.has(entry.action)) throw new Error(`Invalid action: ${entry.action}`);
  if (typeof entry.step !== 'number' || entry.step < 1) throw new Error('Invalid step number');
  if (!entry.timestamp || !new Date(entry.timestamp).getTime()) throw new Error('Invalid timestamp');
  if (typeof entry.label !== 'string' || entry.label.length > 120) throw new Error('Invalid label (max 120 chars)');
  if (entry.metadata !== null && typeof entry.metadata !== 'object') throw new Error('Invalid metadata');
  const FORBIDDEN_KEYS = new Set([
    'personaId', 'confidence', 'tenantId', 'userId', 'sessionId',
    'knownContext', 'context', 'payload', 'reasoning', 'internalReason',
    'debugInfo', 'toolsUsed', 'warnings', 'blockers', 'questionId',
  ]);
  const foundForbidden = Object.keys(entry.metadata || {}).filter(k => FORBIDDEN_KEYS.has(k));
  if (foundForbidden.length > 0) {
    throw new Error(`Forbidden metadata keys: ${foundForbidden.join(', ')}`);
  }
  for (const [k, v] of Object.entries(entry.metadata || {})) {
    if (v !== null && typeof v === 'object' && !Array.isArray(v)) {
      throw new Error(`Nested object in metadata key "${k}" is not allowed`);
    }
  }
}
```

## 9. Safety & Privacy Constraints (Enforced)

| Constraint | Mechanism | Enforced In |
|-----------|-----------|-------------|
| No `this.workLog` instance storage | Per-turn local closure | `createTurnWorkLog()` |
| No tenantId, userId, sessionId | Forbidden key check in `validateWorkLogEntry()` + not in whitelist | test validator + whitelist |
| No raw knownContext or datapoints | No object type in sanitizer; not in any whitelist | `sanitizeMetadataField()` |
| No tool payloads / prompts | No field for them; enum-only gating | `WORK_LOG_METADATA_WHITELIST` |
| No confidence values | Not in whitelist for any action | `WORK_LOG_METADATA_WHITELIST` |
| No personaId | `persona_resolved` exposes `roleLabel` only | `persona_resolved` whitelist |
| No `toolsUsed[]` | Replaced by `toolCount` (number) + `sourceCategory` (enum) | `consultation_synthesis` whitelist |
| No free-text arrays | Only `enum_array` type with explicit `enumCodes` list | `sanitizeMetadataField()` |
| No `questionId` | Removed from `onboarding_question_posed` | `onboarding_question_posed` whitelist |
| No nested objects in metadata | `sanitizeMetadataField` has no 'object' type; `validateWorkLogEntry` checks | Both |
| Max 16 retained entries | `_applyOverflowStrategy()` after every `addEntry()` | `createTurnWorkLog()` |
| Correct `totalActivities` after multiple overflows | Separate closure counter, never derived from `entries.length` | `createTurnWorkLog()` |
| Immutable `toArray()` output | `Object.freeze([...entries])` | `createTurnWorkLog()` |
| Unknown actions dropped silently | `VALID_WORK_LOG_ACTIONS.has(action)` guard | `addEntry()` |
| Labels max 120 chars, no control chars | `.slice(0, 120).replace(/[\x00-\x1f]/g, '')` | `sanitizeWorkLogEntry()` |
| workLog only in agentTrace | New field on `buildAgentTrace()` return value only | `personal-agent.service.js` |
| Additive only — no new REST endpoint | workLog is new field on existing response | `buildAgentTrace()` |
| Minimal callsites — no broad threading | 5 stable instrumentation points in `_executeChatCoreLogic()` scope | Section 6.2 |
